# LogInsight 使用指南

LogInsight 是一款专为开发者设计的 TUI 日志分析工具，支持日志解析、过滤、搜索、AI 诊断和实时追踪。

## 1. 环境准备

### 1.1 从源码编译

需要 Rust 1.75 或更高版本：

```powershell
# 克隆项目
git clone <repository-url>
cd log_analysis

# 编译 (Release 版本)
cargo build --release

# 编译产物位于 target/release/log.exe
```

### 1.2 运行依赖

| 依赖 | 必需 | 说明 |
|------|------|------|
| Windows 10/11 | 是 | 项目目标平台 |
| Windows Terminal | 强烈推荐 | 最佳显示效果，支持 Unicode 字符 |
| Ollama | 否 | 仅 AI 功能需要 |

**注意**: 禁止在 Cursor/VS Code 等集成终端运行，功能键会被拦截。

### 1.3 AI 功能 (可选，但是最好不要用)

如需使用 AI 诊断和聊天功能，需安装并启动 Ollama：

```powershell
# 安装 Ollama (Windows)
# 下载地址: https://ollama.ai/download

# 启动 Ollama 服务
ollama serve

# 默认使用 qwen2.5-coder:7b 模型
# 建议机器配置: 16GB+ 内存
```

## 2. 快速开始

### 2.1 命令行参数

```powershell
# 单文件
log.exe "service.log"

# 多文件 (通配符)
log.exe logs/*.log

# 多文件 (显式列表)
log.exe file1.log file2.log file3.log

# 指定配置文件
log.exe --config custom.toml "service.log"

# 查看帮助
log.exe --help
```

### 2.2 基本操作流程

1. 运行 `log.exe <日志文件>`
2. 日志自动解析并在主视图中显示
3. 使用 `/` 进入搜索模式过滤日志
4. 使用 `F2` 查看统计仪表盘
5. 使用 `a` 键对选中日志进行 AI 诊断

## 3. 视图系统

在主日志视图按对应快捷键切换视图。

| 快捷键 | 视图 | 说明 |
|--------|------|------|
| `F1` | Logs | 主日志列表视图 (默认) |
| `F2` | Dashboard | 可视化统计仪表盘 |
| `F3` | Chat | AI 聊天诊断界面 |
| `F4` | History | 历史命令记录 |
| `F5` | Report | AI 报告生成器 |
| `F6` | Focus | 专注模式 (隔离搜索结果) |
| `t` | Thread | 线程视图 |

### 3.1 Dashboard (F2)

统计仪表盘包含：

- **健康度仪表**: 绿色仪表盘显示 0-100 健康评分
- **错误脉冲**: 迷你图展示近期错误频率
- **源分布图**: 饼状图显示日志来源 Top 5
- **趋势直方图**: 每分钟/小时日志频率及错误趋势
- **预警颜色**: 红色 >500条 | 橙色 >250条 | 青色 正常

### 3.2 Focus 专注模式 (F6)

隔离搜索结果，提供类似浏览器的前进/后退导航：

- `Alt+←` / `Alt+→` 后退/前进
- `Esc` 退出专注模式

### 3.3 Thread 线程视图 (t)

显示同一线程的所有日志：

- 选中日志行后按 `t` 打开
- 青色边框，标题显示 `Thread: <TID> (N 条)`
- 右上角按钮: `[+ Zoom | - Zoom | x Close]`

## 4. 搜索与过滤

### 4.1 快捷搜索 `/`

按 `/` 进入搜索模式：

- 输入正则表达式进行匹配
- `!term` 反向搜索 (排除匹配项)
- `n` / `N` 跳转到下/上一个匹配项
- `Esc` 清除搜索

### 4.2 高级搜索 `Shift+S`

按 `Shift+S` 打开高级搜索面板，支持多条件组合：

- **时间范围**: 开始时间 + 结束时间
- **内容正则**: 日志内容正则匹配
- **来源文件**: 文件名包含过滤
- **日志级别**: Debug / Info / Warn / Error 多选

时间格式支持自然语言：

| 示例 | 含义 |
|------|------|
| `-1h` | 1小时前 |
| `-30m` | 30分钟前 |
| `-2d` | 2天前 |
| `+1h` | 1小时后 |
| `YYYY-MM-DD HH:MM:SS` | 完整格式 |

快捷操作：

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Enter` | 立即执行搜索 |
| `Ctrl+R` | 清空全部条件 |
| `Ctrl+S` | 保存为模板 |
| `Ctrl+L` | 加载模板 |

### 4.3 日志级别过滤 `1/2/3/4`

| 按键 | 级别 | 切换 |
|------|------|------|
| `1` | Info | 切换显示 |
| `2` | Warn | 切换显示 |
| `3` | Error | 切换显示 |
| `4` | Debug | 切换显示 |

标题栏显示当前状态: `[●I ●W ●E ●D]`

### 4.4 文件过滤 `Tab`

多文件模式下按 `Tab` 切换到文件列表焦点：

- `↑/↓` 选择文件
- `Space` 切换文件启用状态
- `Enter` 第一次标记 `[●]`，第二次进入 Solo 模式

### 4.5 链路追踪 `Shift+T`

追踪分布式请求的完整调用链：

1. 选中任意日志行
2. 按 `Shift+T` 自动提取关联 ID (traceId/requestId/correlationId/UUID)
3. 过滤显示相同关联 ID 的所有日志
4. 标题栏显示洋红色 `[FILTER: Trace <ID>]`
5. 再次按 `Shift+T` 或 `Esc` 清除追踪

## 7. AI 诊断功能

### 7.1 单行诊断 `a`

1. 选中需要诊断的日志行
2. 按 `a` 键
3. 自动提取前后 10 行上下文发送给 AI
4. 显示 AI 诊断结果

### 7.2 多轮聊天 `F3`

1. 在 Logs 视图选中关键日志按 `p` 挂载到上下文
2. `F3` 进入聊天界面
3. `i` 进入输入模式
4. Enter 发送消息
5. 支持连续追问，AI 结合挂载日志分析
6. `Esc` 退出聊天

### 7.3 AI 报告生成 `F5`

1. `F5` 进入报告生成视图
2. 选择周期: 今日 / 昨日 / 本周
3. Enter 生成 Markdown 格式报告
4. `Ctrl+C` 复制到剪贴板
5. `Ctrl+S` 保存为 .md 文件

## 8. 实时追踪

按 `f` 切换 Live Tailing 模式：

- 标题显示绿色 `[LIVE]`
- 文件追加内容时自动增量加载
- 适合监控正在写入的日志文件
- 再次按 `f` 退出实时模式

## 9. 配置文件

### 9.1 配置文件位置

主配置文件: `log_config.toml` (项目根目录)

可通过 CLI 指定自定义路径:

```powershell
log.exe --config custom.toml "service.log"
```

首次运行如不存在会自动生成默认配置。

### 9.2 配置项说明

```toml
[parser]
log_pattern = '^(\d{4}-\d{2}-\d{2}\s\d{2}:\d{2}:\d{2}\.\d+)\[([0-9a-f]+):([0-9a-f]+)\]\[(\w+)\]:\s*(.*)\((.+):(\d+)\)\s*$'
timestamp_format = "%Y-%m-%d %H:%M:%S%.3f"

[filters]
fold_threshold = 3                      # 连续重复日志折叠阈值
ignore_patterns = []                   # 忽略的正则模式

# 链路追踪关联 ID 正则
correlation_patterns = [
    '(?i)(?:trace[_-]?id|request[_-]?id|req[_-]?id|correlation[_-]?id|session[_-]?id)[=:\s\"]+([a-zA-Z0-9_-]{8,64})',
    '\b([0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12})\b',
]

# 折叠规则
[[filters.fold_rules]]
name = "USB polling"
match_type = "source_file"
patterns = ["UsbCtrl", "EnumDevice"]

[theme]
slow_threshold_ms = 100               # 慢日志阈值 (黄色高亮)
very_slow_threshold_ms = 1000         # 极慢阈值 (红色高亮)
ip_color = "Cyan"                     # IP 高亮颜色
url_color = "Blue"                    # URL 高亮颜色
path_color = "Yellow"                 # 路径高亮颜色
page_size = 30                         # 翻页行数
```

### 9.3 日志格式

默认支持标准格式日志:

```
2024-01-15 10:30:45.123[1234:abcd][INFO]: Processing request... (handler.rs:42)
```

解析字段: 时间戳 | 进程ID | 线程ID | 级别 | 内容 | 源文件 | 行号

### 9.4 持久化数据

用户数据目录: `~/.loginsight/`

| 文件 | 说明 |
|------|------|
| `history.json` | 搜索/跳转/AI命令历史 (最多1000条) |
| `templates.json` | 保存的搜索模板 |
| `reports.json` | 报告缓存 |

## 10. 注意事项

### 10.1 终端要求

**强烈建议使用 Windows Terminal**，原因：

- 集成终端 (Cursor/VS Code) 会拦截功能键 (F1-F6)
- Windows Terminal 支持完整的 Unicode 字符显示
- 更好的色彩渲染

设置方法:

1. 下载 [Windows Terminal](https://github.com/microsoft/terminal/releases)
2. 打开 Windows Terminal
3. 运行 `log.exe <日志文件>`

### 10.2 权限问题

如果遇到 `os error 5` 拒绝访问：

1. 将日志文件复制到用户目录
2. 或以管理员身份运行
3. 检查文件属性确保有读取权限

### 10.3 编码支持

自动识别并转换：

- **UTF-8**: 默认支持
- **GB18030**: 自动识别 (中文日志)
- **内嵌 JSON**: 自动二次解码

如遇乱码，确保使用 Windows Terminal 或执行 `chcp 65001`。

### 10.4 性能提示

- 日志文件过大时，首次加载可能需要几秒
- 使用搜索过滤减少显示范围可提升响应速度
- `w` 键切换自动换行会影响滚动性能
